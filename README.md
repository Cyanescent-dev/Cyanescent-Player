# Cyanescent Player

**Free native macOS music player and audio-reactive visualiser**

[Download Cyanescent Player 0.9](https://github.com/Cyanescent-dev/Cyanescent-Player/releases/download/v0.9preview/Cyanescent-Player-0.9-Preview-macOS.zip) · [Download 0.9 Fungal Edition](https://github.com/Cyanescent-dev/Cyanescent-Player/releases/download/V0.9-Fungal-Edition/Cyanescent-Player-Fungal-0.9.0-macOS.zip) · [Visit the website](https://cyanescent-dev.github.io/Cyanescent-Player/) · [View releases](https://github.com/Cyanescent-dev/Cyanescent-Player/releases)

Cyanescent Player is a native macOS music player and audio-reactive visualiser for immersive generative worlds, adaptive preset journeys, biofeedback-driven audiovisuals, and music-video creation.

Two free editions are currently available: **Cyanescent Player 0.9** and **Cyanescent Player 0.9 – Fungal Edition**.

This is the public distribution and release website repository. It intentionally does not contain the application source code.

## Choose your edition

### Cyanescent Player 0.9

The standard edition of Cyanescent Player, featuring:

- 20 curated audio-reactive visual presets
- Adaptive and shuffle preset playback with smooth transitions
- Custom preset playlists, importing, and management
- Scion biofeedback input with multiple synthesis and effect modes
- Music-video export up to 1080p

**[Download Cyanescent Player 0.9 for macOS](https://github.com/Cyanescent-dev/Cyanescent-Player/releases/download/v0.9preview/Cyanescent-Player-0.9-Preview-macOS.zip)**

### Cyanescent Player 0.9 – Fungal Edition 🍄

A special free edition created around the strange and beautiful visual world of fungi, slime moulds, and biofeedback.

It includes all the core functionality of Cyanescent Player 0.9, plus:

- **23 unique fungi and slime mould-inspired visual presets**
- Expanded support for **Pocket Scion biofeedback input**
- More robust Scion audio handling
- **Multi-layer synth selection**, allowing multiple Scion synthesis modes to run simultaneously
- Custom combinations of synth layers, letting biofeedback generate richer and more varied soundscapes

Instead of choosing a single Scion synthesis mode, Fungal Edition lets you combine layers — for example, a drone with plucked or percussive elements — to create your own biofeedback-driven instruments.

## Requirements

- macOS 12 (Monterey) or later
- Apple Silicon or Intel Mac

Both editions are signed with a Developer ID certificate and notarised by Apple.

## Install

1. Download your preferred edition using one of the links above.
2. Open the downloaded ZIP file.
3. Move **Cyanescent Player.app** or **Cyanescent Player – Fungal Edition.app** to your Applications folder.
4. Open the application.

## Pocket Scion biofeedback

Cyanescent Player supports input from **Pocket Scion**, allowing biological electrical activity to influence the generated audio and visuals.

In Fungal Edition, the Scion system has been expanded to support multiple synthesis layers simultaneously. Users can select their own combination of synth modes, creating evolving sounds driven by incoming biofeedback data.

This makes it possible to connect living organisms — including fungi — to Cyanescent Player and use their electrical activity as a control source for a generative audiovisual performance.
